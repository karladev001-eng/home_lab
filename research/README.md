# 研究支援エージェントシステム（開発予定）

> このシステムは現在開発中です。

## 概要

論文調査・実験管理・レポート生成などの研究活動を支援するマルチエージェントシステムを予定しています。

## 予定機能

- 論文サーベイ自動化（arXiv・Semantic Scholar 連携）
- 実験ログの自動整理・比較
- 考察・レポートの自動ドラフト生成
- 参考文献管理
