## 構成要素

| 要素 | 種別 | 説明 |
|---|---|---|
| 戻るリンク | Link | 前のページ（検索結果・推薦）に戻る |
| 技術名 + メタ | Heading + Badge | 技術名、item_type、domains、maturity/difficulty/cost |
| 比較に追加ボタン | Button (Outline) | compareStore に追加 |
| 概要セクション | Text | summary を全文表示 |
| 中核メカニズム | Text | core_mechanism |
| 抽象原理 | Text | abstract_principle（強調表示） |
| 目的リスト | Card[] | purpose + condition のペア |
| メリットリスト | Card[] | benefit + condition + evidence_type + confidence |
| デメリットリスト | Card[] | drawback + condition + severity + evidence_type |
| トレードオフリスト | Card[] | gain / cost / condition |
| 有効・避けるべき条件 | List | works_when / avoid_when |
| 代替技術タグ | Badge (clickable) | alternative_to な技術へのリンク |
| 組み合わせ技術タグ | Badge (clickable) | combines_with な技術へのリンク |
| 既知の応用例 | List | known_applications |
| 情報ソース | Card[] | source_type, title, url, retrieved_at, reliability |

## インタラクション

- 代替技術・組み合わせ技術バッジをクリック → /technologies/[id] へ遷移
- 情報ソースのURLをクリック → 新しいタブで外部ページを開く
- 比較に追加 → compareStore + フローティングバー表示
