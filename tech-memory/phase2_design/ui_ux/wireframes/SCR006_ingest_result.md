## 構成要素

| 要素 | 種別 | 説明 |
|---|---|---|
| ソース情報 | Text | URL, タイトル, 種別, 取得日 |
| 新規作成カード | Card (green border) | 新規に作成した技術カードの一覧 |
| 更新カード | Card (blue border) | 既存技術に追加・更新した情報 |
| 技術カードを見るリンク | Link | /technologies/[id] へ遷移 |
| 別のURLを収集するボタン | Button (Outline) | /ingest へ戻る |
| 検索トップへボタン | Button (Ghost) | / へ遷移 |

## インタラクション

- 「技術カードを見る」クリック → /technologies/[id] へ遷移
- 「別のURLを収集する」クリック → /ingest へ戻る（URLフォームをクリア）
- 「検索トップへ」クリック → / へ遷移
