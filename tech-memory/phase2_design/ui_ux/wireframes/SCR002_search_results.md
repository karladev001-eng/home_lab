## 構成要素

| 要素 | 種別 | 説明 |
|---|---|---|
| 検索バー | TextInput | 現在のクエリを表示・再検索可能 |
| 検索モードタブ | RadioGroup | 現在のモードをハイライト |
| フィルタバー | Select × 3 | 分野・成熟度・実装コストで絞り込み |
| ヒット件数 | Text | 「N件ヒット」 + クエリテキスト |
| 技術カード | Card | fit_score降順で並ぶ。★はfit_score >= 0.9 |
| 比較に追加ボタン | Button (Outline) | compareStore に追加。最大4つ |
| 詳細を見るリンク | Link | /technologies/[id] へ遷移 |
| ページネーション | Pagination | 1ページ10件 |

## インタラクション

- フィルタ変更 → URLパラメータ更新 → 即時再検索
- 比較に追加 → 画面下部にフローティングバー「2件選択中 [比較する]」が現れる
- 比較するボタン → /compare へ遷移
- 検索中: カードエリアにスケルトン表示

## 技術カードのデザイン

各カードには以下を表示:
1. 技術名 + fit_score バッジ（色分け: >= 0.9 green, >= 0.7 yellow, < 0.7 gray）
2. item_type ラベル + ドメインタグ
3. summary（最大2行で切り捨て）
4. メリット1件 + デメリット1件（条件なしの主要なもの）
5. 詳細を見るリンク
