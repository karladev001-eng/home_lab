# URL収集 ワイヤーフレーム

## 画面ID: SCR005
## URL: /ingest
## 目的: URLを入力して技術情報を収集し、技術カードを自動生成する

│  ┌──────────────────────────────────────────────────────────┐   │

## 構成要素

| 要素 | 種別 | 説明 |
|---|---|---|
| 入力タブ | Tabs | URL収集 / キーワード収集 / 手入力メモ |
| URLテキストボックス | TextInput | type=url, バリデーション: http(s)://, 1000文字以内 |
| 収集深度 | RadioGroup | light / standard / deep, デフォルト: standard |
| タグ入力 | TextInput | カンマ区切り。入力後にタグチップとして表示 |
| 収集開始ボタン | Button (primary) | 送信中はdisabled + スピナー |
| プログレスバー | Progress | 収集中に表示（0→100%） |
| ステップ表示 | Text | 「URL取得中...」「解析中...」等のリアルタイム表示 |

## インタラクション

- URL入力後にEnterまたは「収集開始」ボタンクリック → 収集処理開始
- 収集中: ボタンdisabled + プログレスバー表示
- 成功 → /ingest/result へ遷移（収集結果を渡す）
- エラー → Toast でエラーメッセージ表示、フォームを再表示

## バリデーション

- URLが空: 「URLを入力してください」
- URLが不正: 「http:// または https:// で始まるURLを入力してください」
- URLが1000文字超: 「URLが長すぎます（1000文字以内）」
- タグが50文字超: 「タグは50文字以内で入力してください」
