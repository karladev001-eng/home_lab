## 構成要素

| 要素 | 種別 | 説明 |
|---|---|---|
| 比較軸チェックボックス | Checkbox group | 表示する比較軸を選択（デフォルト: 主要4軸） |
| 比較テーブル | Table | 比較軸 × 技術のマトリクス。横スクロール可 |
| スコア表示 | Stars (readonly) | 0-5のスター評価（APIから返されるfit_scoreから変換） |
| 根拠テキスト | Text (small) | スコアの根拠を1-2行で表示 |
| 総合推薦 | Alert | LLMが生成した総合的な推薦コメント |
| 技術詳細リンク | Link | 各技術の /technologies/[id] へ |

## インタラクション

- 比較軸チェックボックスを変更 → テーブル列がリアルタイム更新
- テーブルは横スクロール対応（モバイル対応）
- 技術詳細リンクをクリック → /technologies/[id] へ遷移
