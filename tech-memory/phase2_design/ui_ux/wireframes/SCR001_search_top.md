# 検索トップ ワイヤーフレーム

## 画面ID: SCR001
## URL: /
## 目的: 技術名・課題・分野・比較から技術情報を検索する

## レイアウト（ASCII ワイヤーフレーム）

```
┌─────────────────────────────────────────────────────────────────┐
│  [tech-memory]    [検索]  [収集]  [推薦]                          │  ← 固定ナビ
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│              tech-memory                                         │
│        技術・アルゴリズム・設計パターン検索                           │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  技術名・課題・分野を入力 ...                               │   │ ← 検索バー
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  検索モード: [技術名] [課題] [分野] [比較]                          │ ← タブ or ラジオ
│                                                                  │
│  ┌──────────────────────┐                                       │
│  │  [ 検索 ]             │                                       │ ← 検索ボタン
│  └──────────────────────┘                                       │
│                                                                  │
│  ─────────── 検索例 ───────────                                  │
│                                                                  │
│  課題から:  「少ない試行回数で良い候補を見つけたい」                   │ ← クリックで入力
│  技術名:   「Behavior Tree」 「RAG」 「ECS」                       │
│  分野:     「ゲームAI」 「LLMシステム」 「バックエンド設計」           │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 構成要素

| 要素 | 種別 | 説明 |
|---|---|---|
| ナビバー | Navigation | 固定ヘッダー。tech-memory ロゴ + 検索/収集/推薦リンク |
| 検索バー | TextInput | プレースホルダー: 「技術名・課題・分野を入力 ...」, Enter で検索実行 |
| 検索モードタブ | RadioGroup | 技術名 / 課題 / 分野 / 比較。デフォルト: 課題 |
| 検索ボタン | Button | Primary, type=submit |
| 検索例リスト | Button (Ghost) | クリックすると検索バーに値を入れて検索実行 |

## インタラクション

- Enter キーまたは検索ボタンで /search へ遷移（クエリパラメータ付き）
- 検索例をクリック → 検索バーに値をセット → 自動検索実行
- 検索モードは URL パラメータ `?mode=problem_search` 等で保持

## レスポンシブ

| ブレークポイント | 変更点 |
|---|---|
| < 768px | ナビリンクをハンバーガーメニューに格納 |
| > 1024px | 検索バーの最大幅を700pxに制限しセンタリング |
