## 構成要素

| 要素 | 種別 | 説明 |
|---|---|---|
| goalテキストエリア | Textarea | 課題・目標を自由記述。3-5行表示 |
| 制約タグリスト | Badge + Input | タグ形式で制約を管理。Enterで追加、×で削除 |
| 推薦を取得ボタン | Button (primary) | API呼び出し |
| 推薦候補カード | Card[] | fit_score順。理由・実装ノート付き |
| 避けるべき技術 | Card (red border) | 条件に合わない技術と理由 |
| 詳細を見るリンク | Link | /technologies/[id] へ遷移 |

## インタラクション

- 「推薦を取得」ボタン → POST /api/v1/recommend を呼び出す
- ローディング中: スケルトン表示
- 技術カードの「詳細を見る」→ /technologies/[id] へ遷移
