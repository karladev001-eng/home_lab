Behavior Tree

アーキテクチャパターン ゲーム開発 ロボティクス AIエージェント
成熟度: mature 難易度: medium コスト: low
概要

複雑な意思決定を、条件判定と行動選択の階層構造として管理する設計パターン。各ノードはCondition（条件）またはAction（行動）であり、木構造を再帰的に評価することで複雑な行動フローを実現する。Sequence（AND）とFallback（OR）の組み合わせで多様な意思決定を表現できる。

中核メカニズム

ルートノードから葉ノードへ評価を順番に行い、各ノードがSuccess / Failure / Running のいずれかを返す。Sequence ノードは全子ノードがSuccessで自身もSuccess、Fallback ノードはいずれかがSuccessで自身もSuccess。再帰的なトラバーサルにより階層的な意思決定を実現する。

抽象原理
複雑な意思決定を、階層化された条件判定と行動選択に分解し、再利用可能な木構造で管理する原理
目的
NPCの行動フローを階層的に管理したい
条件: 複数の行動状態が存在し、優先度による選択が必要な場合
複雑な意思決定ロジックをデバッグ・可視化したい
条件: 行動ツリーの可視化ツールが利用可能な場合
